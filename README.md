# E-commerce Product Classification Using NLP

## Overview
This project classifies e-commerce product descriptions into four categories using Natural Language Processing (NLP).

## Categories
- Books
- Clothing & Accessories
- Electronics
- Household

## Technologies
- Python
- Pandas
- Scikit-learn
- TF-IDF
- Logistic Regression
- Matplotlib

## Methodology
1. Load and inspect the dataset.
2. Check missing values and duplicate records.
3. Clean the data and analyze class distribution.
4. Split the dataset into training and testing sets.
5. Transform product descriptions using TF-IDF.
6. Train a Logistic Regression classifier.
7. Evaluate the model using accuracy, precision, recall, and F1-score.

## Results
- Model: Logistic Regression
- TF-IDF features: 10,000
- Test samples: 5,557
- Accuracy: 95.29%

## Dataset
The dataset is loaded from the public GitHub CSV source used in the notebook.

## How to Run
Open the notebook in Google Colab and run the cells in order.
